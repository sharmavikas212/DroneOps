# DroneOps — Progress Tracker

## Project Goal
Build a native Android drone-operator dashboard demonstrating practical
Android engineering skills.

Planned features:
- Simulated live telemetry
- Connection loss and recovery
- Flight history and local persistence
- Automated tests
- Optional post-flight AI report

Technology:
Kotlin, Jetpack Compose, MVVM, Coroutines, Flow, Room, JUnit,
and potentially Hilt.
